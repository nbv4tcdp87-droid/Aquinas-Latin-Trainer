Sentence Analysis

Pick a sentence from the Summa. Above nouns and pronouns, set case / number / gender; above verbs, set person / number / tense / mood; above infinitives, set tense / voice. Below each word, choose how it's used in the sentence — for a subjunctive verb, why it is subjunctive; for adjectives and participles, which noun they agree with; and for relative pronouns, the noun they refer to.
